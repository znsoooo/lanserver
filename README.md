# 局域网服务器（LAN Server）

一个轻量的安卓局域网文件共享工具：把手机上某个目录通过 **HTTP** 或 **FTP** 暴露到局域网，
同一 Wi-Fi 下的电脑/手机用浏览器或 FTP 客户端即可访问、下载该目录里的文件。

包名：`com.znsoooo.lanserver` ｜ `minSdk 21` ｜ `targetSdk / compileSdk 34`

发布 APK 下载：https://github.com/znsoooo/lanserver/releases

## 一、功能与界面

打开 App 后界面自上而下依次为：

| 行 | 内容 | 说明 |
|----|------|------|
| 1 | **本机地址**（IP + 端口） | 自动读取手机首个可用 IPv4 地址，切换网络时由系统回调自动更新，没有手动刷新入口；右侧端口输入框（默认 `8888`）；访问地址随 IP/端口/类型变化实时刷新 |
| 2 | **服务器类型** | 分段按钮点选 `HTTP` 或 `FTP`（选中项高亮为蓝青渐变，未选中项仅描边、无阴影）。**两种协议共用同一个端口**，这里的点选只决定界面上显示的网址前缀 |
| 3 | **访问网址** | 实时显示当前访问地址，点右侧「复制」按钮复制 |
| 4 | **共享目录** + 「选择」按钮 + 路径文本 | 默认 `/storage/emulated/0`（内部存储根）；点「选择」打开 App 自带的文件夹选择器，可进入存储根、`Download` 等系统选择器不允许的目录；点右侧「复制」按钮复制 |
| 5 | **允许写入** 开关 | 默认关闭；开启后 HTTP 模式可在网页上传文件、FTP 模式允许 STOR/MKD/RMD/DELE 写入操作（`@Favorite` 内始终只读） |
| 6 | **显示隐藏文件** 开关 | 默认关闭；开启后名称以 `.` 开头的文件/文件夹也会在列表中显示 |
| 7 | **启动 / 停止服务** 按钮 | 打开 App 时**自动启动**服务，启动成功后按钮显示「停止服务」，再点一下即停止；启动失败（如端口被占用）会提示并保持未启动状态。访问地址与二维码**始终显示** |
| 8 | **访问地址二维码** | 始终显示，扫码即可在另一台设备打开 |

目录列表的**排序规则**：文件夹排在文件前面，同级按名称字母序（**不区分大小写**）排列。

- **HTTP 目录页**：已加 `viewport` 适配手机浏览器（字号更大、更易点按）；**文件右侧显示大小**（如 `1.2 MB`），**文件夹右侧显示内部项数**（如 `3 项`，即该文件夹内文件与子文件夹的数量；是否统计隐藏项与「显示隐藏」开关同步）。
- **界面设置记忆**：服务器类型、端口、共享目录、允许写入、显示隐藏等设置会**自动记忆**，下次打开 App 直接载入上次状态。

## 二、使用步骤

1. 手机连接到 Wi-Fi / 局域网（需与访问端在同一网段）。
2. 首次启动按提示授予「所有文件访问」权限；之后点「选择」打开自带的文件夹选择器，逐级进入目标目录，底部「选择此文件夹」确认。
3. 选择界面显示的类型（HTTP 或 FTP）、确认端口（默认 8888）。
4. 服务在打开 App 时已自动启动，顶部状态显示「运行中」；记下界面显示的访问地址，或扫二维码。若此前手动停止过，点「启动服务」重新启动。
5. 在电脑浏览器 / FTP 客户端访问该地址：
   - **HTTP 模式**：浏览器直接打开 `http://手机IP:端口/`，可浏览目录、点击文件下载；开启「允许写入」后，目录页面右上角出现「上传文件」按钮，选择文件即上传到**当前所在目录**。
   - **FTP 模式**：用 FTP 客户端连接 `ftp://手机IP:端口/`（匿名登录，支持被动/主动模式、列目录、下载、上传）；仅当开启「允许写入」时允许 STOR/MKD/RMD/DELE 写入操作，否则服务器拒绝写入并返回 550。

> 两个协议监听的是**同一个端口**：服务启动后，用浏览器访问是 HTTP，用 FTP 客户端连接就是 FTP，按连接首行自动识别，互不干扰。
> 访问地址随「本机 IP / 端口 / 类型」变化实时刷新；切到其它网络时 IP 由网络状态回调**自动刷新**。运行中修改以下任意一项都会**立即套用新配置**：服务器类型、端口、「允许写入」、「显示隐藏」开关，以及**共享目录**（重新选择目录后即时生效）。App 切到后台或发生旋转等配置变更时，**服务不会随之关闭**，仍在后台持续运行。

## 三、共享目录、权限与 `@Favorite`

### 1. 直接用真实路径访问

App 申请「所有文件访问」（`MANAGE_EXTERNAL_STORAGE`），文件操作全部走 `java.io.File`，
因此拿到的是真正的 `/storage/emulated/0/...` 路径，不再受 SAF 的 `content://` 授权范围限制。

### 2. 自带的文件夹选择器

系统自带的 SAF 选择器从 Android 11 起不允许把**存储根目录**作为选择结果，部分 ROM 连 `Download` 也选不了。
所以 App 内嵌了一个自己的选择器：

- 逐级进入目录，顶部显示当前完整路径（可横向滑动），右侧「上级」返回上一层；
- 目录内的**文件也会列出来**（带大小），只作参照，点它不会选中；
- 文件夹右侧显示「X 项」，即该文件夹内的直接子项数量；
- 当前所在目录就是选中项，点底部「选择此文件夹」确认；
- 系统返回键直接退出选择器（取消）；隐藏项（`.` 开头）不显示。

### 3. `@Favorite` 虚拟收藏目录

当共享目录内存在系统标记为「收藏」的文件时，共享根下会多出一个 **`@Favorite`** 目录：

```
共享目录：/storage/emulated/0
  DCIM/work/IMG_001.JPG（已收藏）
  Download/报告.pdf（已收藏）

共享根下的 @Favorite：
  @Favorite/DCIM/work/IMG_001.JPG
  @Favorite/Download/报告.pdf
```

- 按**原路径结构**镜像，只在共享根这一层出现，子目录里不会重复；
- 收藏范围只取**当前共享目录之内**的文件，换共享目录后随之变化；
- 纯视图，不复制、不移动数据，原文件位置不变；
- **只读**：HTTP 返回 `403`、FTP 返回 `550 Read-only: @Favorite is a virtual view.`；
- 名称以 `@` 开头，列表中恒定置顶，也避免与普通目录重名。

> 收藏数据来自系统的 `MediaStore`（`is_favorite` 列，Android 11+）。如果相册/文件管理器没有写入过收藏标记，这个目录就不会出现，属正常现象。

## 四、注意事项与已知限制

- **防火墙 / 厂商限制**：部分 ROM 会拦截非特权端口的入站连接。若连不上，可换端口，
  或检查该 App 的「网络权限 / 后台数据 / 不受限制的数据」等设置。
- **HTTP 为简化实现**：自实现轻量 HTTP/1.0，支持目录浏览与文件下载、常见类型 MIME，
  开启「允许写入」后支持 `multipart/form-data` 网页上传；不带鉴权，仅适合**可信局域网内**临时共享。
- **FTP 为简化实现**：匿名、无密码鉴权，支持被动（PASV）/主动（PORT）、
  `LIST / CWD / PWD / RETR / STOR / SIZE` 等常用命令；`STOR/MKD/RMD/DELE` 写入命令仅在「允许写入」开启时可用；
  不支持断点续传等高级特性。
  个别手机浏览器不能直接访问 `ftp://` 地址（受浏览器自身限制），建议用 FTP 客户端。
- **服务存活**：服务器运行在后台线程，App 切到后台（返回桌面 / 息屏）或发生旋转等配置变更时**不会关闭**，仍在后台持续运行；仅当进程被系统强杀（如从最近任务强行划掉）时服务才会停止。若需被杀后仍常驻，可后续改为前台服务（带常驻通知）。
- **受限目录**：`Android/data`、`Android/obb` 等目录即使有「所有文件访问」权限，部分 ROM 仍拒绝读取，选择器会提示「无法读取该目录」。
- **应用图标**：只有自适应矢量图标（`mipmap-anydpi-v26`），没有各密度 PNG 兜底；Android 8.0 以下桌面可能显示默认图标或空白。

## 五、编译方法

### 环境要求

- **JDK 17**（或兼容版本）
- **Android SDK**（`ANDROID_HOME` 指向 SDK 目录），需含 **SDK Platform 34** 与 **build-tools**
- **Gradle 8.2**

### 步骤

```bash
# 1. 设置 Android SDK 路径
export ANDROID_HOME=/opt/android-sdk      # 按你的 SDK 实际位置修改

# 2. 进入工程目录
cd lanserver

# 3. 编译 Debug 包（产物名为 lanserver-debug.apk）
/root/gradle-8.2/bin/gradle clean assembleDebug --no-daemon

# 4. 取产物
ls app/build/outputs/apk/debug/lanserver-debug.apk
```

### 主要源码结构

```

```
